# 🔥 Taobi · 治疗准备型逃避 · 菜单栏小工具

把《21 天刻意练习》那套**反"准备型逃避"**的训练，做成常驻 macOS 菜单栏的小工具，
帮你每天 **check（今日动作打勾）· 决策（60 秒拍板）· 记录（焦虑校准 / 启动延迟）**。

> 你练的不是自律、不是效率，是一块很具体的肌肉：
> **在没准备好的状态下行动、并把不完美的东西交出去。**
> 判断标准只有一条——*如果某个练习没让你感到不适，它就不算数。*

---

## 菜单栏长这样

标题实时显示进度：`🔥 第5天 · 3/5`，点开下拉菜单：

```
今日 · 周1 · 零风险、私密、可逆
─────────────────────────────
○ ① 决策秒杀（0/3）        ▸ ＋ 添加一个决策（60 秒拍板）
○ ② 五分钟启动
○ ③ 每日一发 ★核心
○ ④ 留一个不完美
○ ⑤ 晚间复盘
─────────────────────────────
🎯 焦虑校准                ▸ 发之前 · 记录预测 / 发之后 · 记录实际
⏱ 启动延迟                ▸ 我决定要做某事 / 我真正动手了
📊 数据与趋势
🅿️ Parking List（新点子丢这里）
─────────────────────────────
⚙️ 设置 ▸  ·  关于这套练习  ·  退出
```

打勾即 `✓`，跨天自动重置；漏一天不补、不自责，第二天继续。

## 功能 ↔ 练习对应

| 菜单 | 对应练习 | 做什么 |
|---|---|---|
| **① 决策秒杀** | 早上 5 分钟 | 记 3 个双向门小决策，每加一个就弹 60 秒倒计时通知，到点拍板不回头 |
| **② 五分钟启动** | 挑最逃避的事 | 一键启动 5 分钟计时，到点通知"即止"——练"启动"不练"完成" |
| **③ 每日一发 ★核心** | 暴露疗法核心 rep | 交出一件**低于满意标准**的东西并记下它是什么 |
| **④ 留一个不完美** | 刻意为之 | 一个开关：故意留个无关紧要的瑕疵不碰，观察"天塌了吗" |
| **⑤ 晚间复盘** | 5 分钟 | 写下今日复盘笔记 |
| **🎯 焦虑校准** | 最关键一环 | 发之前记预测、发之后记实际（0-10），用数据打掉"系统性高估后果" |
| **⏱ 启动延迟** | 量化体温计 | "我决定了"→"我动手了"两下点击，自动算出延迟分钟数 |
| **📊 数据与趋势** | 看证据 | 启动延迟 14 天火花线 + 周对比；焦虑预测 vs 实际的高估差距 |
| **🅿️ Parking List** | 铁律 1 | 冒出来的新方向丢这里，练习期只把一个东西推到底 |

> **4 周渐进暴露**：菜单顶部会根据开始日期自动显示当前周的"每日一发"难度
> （周1 私密可逆 → 周2 少量受众 → 周3 真实利害 → 周4 对外死线）。
> 每天早 9 点 / 晚 9 点有系统通知提醒未完成的动作。

## 安装与运行

### 方式 A：开发模式（最快，推荐先试）

```bash
git clone <this-repo> && cd Claude-Health-Tool
./run.sh          # 自动建 venv、装 rumps、启动
```

启动后看屏幕**右上角菜单栏**的 🔥。关掉终端会退出；想常驻请用方式 B。

手动版：

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python run_app.py
```

### 方式 B：打包成原生 .app（常驻 / 开机自启）

```bash
pip install py2app rumps
python setup.py py2app
open dist/Taobi.app           # 驻留菜单栏，不占 Dock
```

设开机自启：`系统设置 → 通用 → 登录项 → +` 选 `dist/Taobi.app`。
（首次通知需在 `系统设置 → 通知` 里允许 Taobi。）

## 数据

- 全部记录存在本地 `~/.taobi/data.json`，纯文本、可随时查看 / 备份。
- 菜单 `⚙️ 设置 → 查看数据文件位置` 可看到路径。
- 没有任何联网、没有账号——你的练习记录只在你机器上。

## 开发 / 测试

逻辑层（`taobi/storage.py`、`taobi/stats.py`）是纯 Python，可在任意平台跑测试：

```bash
python tests/test_logic.py        # 11 个用例，无需 macOS / rumps
```

`taobi/app.py` 是 rumps UI 层，只在 macOS 上运行。

```
taobi/
  storage.py   # 数据持久层（JSON）
  stats.py     # 趋势 / 焦虑校准统计
  app.py       # 菜单栏 UI（rumps）
tests/
  test_logic.py
```

## 三条铁律（写在这里提醒自己）

1. 练习期**禁止开新方向**——新点子丢 Parking List，只把一个东西推到底。
2. **"再准备一下"是禁用词**——一旦冒出来，就当成"该发了"的信号。
3. **漏一天不补、不自责**，第二天继续。
